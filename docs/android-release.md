- 리뷰어 안내에 서울 소재 홍제인왕영어 학원의 등록 학생용 단어 학습·숙제 앱임을 명시. 심사 접속은 위치 제한 없이 가능하며 결제·OTP·개인 Google 계정이 필요 없고, FCM 알림은 선택 사항이라고 설명. Play 저장 완료 메시지 확인.
- IARC 설문 최종 저장: 교육 제품, 온라인 단어 콘텐츠, 결제·위치 공유 없음. 한국 전체이용가, PEGI 3 등 결과 확인.
- 타겟 연령 6–8세 및 9–12세 저장. 사용자가 보호자 동의 확인 및 어린이 법규 준수 보증 선언을 승인한 후 적용.
- 데이터 보안 8개 유형 최종 저장. 계정 전체 삭제 및 부분 기록 삭제 모두 공개 delete-account.html 안내 URL 사용. 이 페이지는 문의 절차이며 삭제 권한·학생 자료·PIN을 노출하지 않음.
- 앱 콘텐츠 화면에서 주의 필요 선언 없음 확인. 게시 개요의 제출 대기 변경사항 12개, 차단 문제 1개: 대한민국 개발자 계정 추가 정보.
- 조직 계정의 기존 앱 계획에는 인앱 구매·정기 결제·광고 수익화가 등록되어 있음. 이번 무료 앱의 심사만을 위해 조직 전체 계획을 임의 변경하지 않음. 사업자등록번호와 통신판매업 신고번호·신고기관의 실제 정보를 사용자에게 요청했으며 임의 번호 또는 면제 선언을 입력하지 않음.
- 모바일 심사 제출 Release Gate: Block (개발자 계정 정보 미완료). 앱별 선언 및 관련 사용자 승인은 해소됨. 비공개 Alpha 심사 제출 버튼은 비활성이고 프로덕션 공개는 하지 않음.

### 비공개 심사 제출 완료 및 미발급 정보 확인 (2026-10-10)
- 사용자가 제공한 사업자번호와 현재 상호 제로원이 홈택스 사업자 선택 화면에서 일치함을 확인. 증명서 및 개인정보 원문은 저장소에 포함하지 않음.
- 공정위 공개 조회에서 해당 번호의 통신판매업 등록 내역 없음. 사용자가 신고하지 않은 것으로 확인한 뒤 번호·발급기관에 실제 미발급 상태인 ‘없음’을 입력. Play의 저장 완료 메시지와 제출 차단 해소 확인. 정부24 신고 신청·세금 납부는 진행하지 않음.
- Google 공식 안내는 한국 개발자의 유료 앱·인앱 구매 앱에 통신판매업 정보를 요구함: https://support.google.com/googleplay/android-developer/answer/3255733?hl=ko 및 https://support.google.com/googleplay/android-developer/answer/6223646?hl=ko . 다만 ‘없음’ 입력을 명시적으로 허용하는 공식 문구는 확인하지 못함. UI 저장·검사 성공 및 공개 앱 사례는 정책 승인 보장과 구분함.
- 모바일 심사 제출 Release Gate: Conditional (수동). 기능·자료 검증 완료, 차단 오류 해소. 미발급 정보 처리의 최종 정책 판단은 Google 검토에 따르며 보완 요청 시 대응한다. 계정 전체의 수익화 계획은 변경하지 않음.
- 사용자 기존 승인 범위대로 Alpha 비공개 테스트 변경사항 12개를 Google Play에 전송. 자동 검사 완료 후 게시 개요의 ‘검토 중인 변경사항’ 및 ‘변경사항을 검토 중입니다’ 표시 확인.
- 최종 심사 승인 또는 공개 출시 완료를 의미하지 않음. 프로덕션 버전은 생성·출시하지 않음.

### 프로덕션 공개 출시 추가 제출 (2026-10-10)
이 절은 위의 공개 출시 보류 결정을 갱신한다. 사용자가 일반 공개도 함께 제출하도록 요청했다.
- 기존 검증된 App Bundle 1(1.0), 최소 API 24 및 타겟 SDK 36을 라이브러리에서 프로덕션에 추가. 출시명 ‘1.0 · 인왕보카 첫 공개 출시’ 및 한국어 출시 노트 저장.
- 배포 국가 대한민국 1개 설정. 국가 미지정 오류 해소 후 차단 오류 없음 확인. 기존 가독화 파일·네이티브 디버그 기호 경고 2개는 비차단 안내로 유지.
- 추가 제출 시 기존 Alpha 검토를 취소하고 다시 시작한다는 Play 안내를 확인한 뒤 공개 출시 요청에 따라 제출. 게시 개요의 제출 대기 항목이 사라지고 프로덕션 ‘전체 출시 시작’과 Alpha가 함께 ‘검토 중인 변경사항’에 포함됨을 확인.
- 현재 빠른 자동 검사 진행 중. 검사 성공 시 Google 검토로 전송되며 최종 승인 완료를 뜻하지 않음. 관리형 게시가 사용 중지되어 승인 후 별도 수동 게시 없이 대한민국 공개 출시가 진행되는 설정.
- 공개 출시 설정 변경 Spec/Design Gate: Pass (수동, 사용자 공개 출시 요청·기존 빌드 재사용·대한민국 배포). Code Gate: Approved (수동, 코드 변경 없음 및 기존 검증 결과 유지). Release Gate: Conditional (수동, 기존 미발급 정보 정책 판단 및 Google 자동 검사·심사 결과 대기).
