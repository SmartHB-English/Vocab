# 서버 사용량 — 얼마나 읽히나

파이어스토어 무료 몫: **하루 읽기 5만 건 · 쓰기 2만 건** (문서 한 개 = 한 건).
서버를 한 번 부르면 문서 여러 개를 읽는다. `체크자료` 한 번은 학생 · 숙제 · 기록 · 기록보관 · 숙제예약을 다 읽는다.

## 지금 서버를 읽는 자리 (2026-11-18, 프롬프트 58)

| 화면 | 언제 읽나 | 하루 몇 번쯤 |
|---|---|---|
| check.html | 들어올 때 한 번 (`학생번호채우기` + `체크자료`) | 원장님이 여는 만큼, 1~3번 |
| check.html | 날짜가 바뀔 때 (30초 시계는 날짜만 보고, 바뀐 날에만 `체크자료`) | 켜 둔 날 1번 |
| check.html | 「↻ 새로 불러오기」 를 누를 때 | 누르는 만큼, 10번 안팎 |
| teacher.html | 로그인 · 「↻ 새로고침」 · 저장한 뒤 (`loadTeacher`) | 수십 번 |
| teacher.html | 1분 넘게 가려졌다가 다시 보일 때 (되풀이 시계가 아니라 보일 때 한 번) | 창을 오갈 때마다, 수십 번 |
| index.html (아이) | 로그인 · 화면마다 「↻」 · 시험 「↻ 새로고침」 · 기록 보내기 | 아이 한 명당 수십 번 |
| parent.html | 로그인 · 볼 때 | 학부모 한 명당 몇 번 |

저절로 되풀이해 읽는 시계는 **없다**. 남은 `setInterval` 은 모두 서버를 안 읽는다 —
시험 시계 · 제한시간 시계 · 짝맞추기/퍼즐 초 세기 · 시험 감시(1초) · check.html 날짜 넘기기(30초).

예전 check.html 은 1분마다 `체크자료` 를 불러 하루 1,440번 × 문서 수십~수백 개를 읽었다. 그것 하나로 무료 몫을 넘겼다.

## 새로 만들 때 지킬 것

1. **저절로 되풀이해 읽지 않는다.** `setInterval` · 되부르는 `setTimeout` 안에서 서버를 부르지 않는다.
2. **사람이 누를 때 읽는다.** 새로고침 단추를 두고, 읽는 동안 잠그고, 「몇 시 기준」 을 보인다.
3. 꼭 되풀이해야 하면 — **몇 분마다인지, 하루 몇 번 · 문서 몇 개인지**를 이 표에 먼저 적고 원장님께 묻는다.
4. 쓰기는 손댄 것만, 모아서 보낸다 (check.html 의 1.5초 디바운스처럼).
5. Firebase 콘솔 「결제 → 예산 및 알림」 에 알림을 걸어 둔다.
